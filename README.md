# CRM — управление клиентами

Учебный Django-проект для учёта услуг, рекламных кампаний, потенциальных клиентов, контрактов и активных клиентов.

## Возможности
- Авторизация и выход пользователя.
- CRUD для услуг, рекламных кампаний, потенциальных клиентов и контрактов.
- Создание активного клиента только из потенциального клиента с созданием контракта.
- Статистика кампаний: потенциальные клиенты, активные клиенты, сумма контрактов, бюджет и отношение дохода к рекламным расходам.
- Разграничение доступа по стандартным Django permissions и группам.
- Административная панель Django для пользователей, групп и разрешений.
- PostgreSQL по умолчанию; SQLite используется только если переменная `DB_NAME` не задана (удобно для быстрого ознакомления).

## Запуск (Linux / WSL)
Требуются Python 3.11+ и PostgreSQL.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
cp .env.example .env
```

Создайте базу и пользователя PostgreSQL (пример, выполните в `psql` под администратором БД):
```sql
CREATE USER crm_user WITH PASSWORD 'change-this-password';
CREATE DATABASE crm_db OWNER crm_user;
```
Задайте в `.env` реальные параметры базы и секретный ключ. Затем:
```bash
python manage.py makemigrations services campaigns leads contracts active_clients
python manage.py migrate
python manage.py createsuperuser
python manage.py seed_roles
python manage.py runserver
```
Откройте http://127.0.0.1:8000/ и для административной панели http://127.0.0.1:8000/admin/.

## Роли
Команда `seed_roles` создаёт группы:
- **Оператор** — просмотр/создание/изменение потенциальных клиентов.
- **Маркетолог** — просмотр/создание/изменение услуг и рекламных кампаний.
- **Менеджер** — просмотр потенциальных клиентов, управление контрактами и активными клиентами, просмотр кампаний и статистики.
- **Просмотр статистики** — доступ к аналитике для всех сотрудников.

Администратор создаётся через `createsuperuser` и управляет пользователями, группами и разрешениями в `/admin/`. Удаление доступно суперпользователю/персоналу; обычным ролям оно намеренно не выдано по умолчанию. Разрешения можно изменить в админке.

## Важные замечания
- Это готовый учебный каркас с рабочими CRUD-страницами, а не production-система. Перед реальным использованием добавьте HTTPS, резервное копирование, аудит действий, ограничения загрузки файлов и настройте безопасные секреты.
- Денежные поля используют `DecimalField`.
- Статистика суммирует суммы контрактов, связанных с активными клиентами, привлечёнными соответствующей кампанией. Для показателя доход/расход возвращается процент покрытия рекламного бюджета; если бюджет равен нулю, показатель отображается как «—».
- Для проверки стиля: `pylint --load-plugins pylint_django config services campaigns leads contracts active_clients`.
